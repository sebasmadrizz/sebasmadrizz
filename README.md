## Proyecto destacado

### [movie-analysis](https://github.com/sebasmadrizz/movie-analysis)

Plataforma de BI y Machine Learning construida sobre un conjunto de datos de 5,000 películas.

- Pipeline de datos por etapas sobre PostgreSQL, con feature store en SQL y prevención de fuga temporal.
- Modelo de predicción de ingresos servido por una API REST con FastAPI.
- Dashboard de BI y predictor en React.
- Pruebas automatizadas con pytest y entorno reproducible con Docker y Makefile.

*Estado: en desarrollo activo.*
